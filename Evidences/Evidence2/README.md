Cómo correr el programa

Para compilar y ejecutar cualquiera de los dos programas, necesitas tener un compilador de C++ y abrir tu terminal exactamente dentro de la carpeta src del proyecto.

Para probar la Parte A que valida las estructuras de datos, corre este comando para compilar:
g++ partA.cpp -I ../include -o partA
Y luego ejecútalo así:
.\partA.exe

Para correr la Parte B, que es el menú interactivo para el análisis de los logs, compila el código principal con este comando:
g++ main.cpp -I ../include -o mainB
Y luego ábrelo con:
.\mainB.exe
